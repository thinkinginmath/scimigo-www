# Chrome Extension Downloads

This directory hosts the SciMigo Chrome Extension beta files for testing.

## Setup Instructions:

1. **Place your ZIP file here**: 
   - Copy your built extension ZIP file to this directory
   - Rename it to: `scimigo-extension-beta.zip`

2. **Deploy the site**: 
   - The page will be available at: `https://www.scimigo.com/chrome-extension-beta`
   - The download link will be: `https://www.scimigo.com/downloads/scimigo-extension-beta.zip`

3. **Share with testers**:
   - Send them the URL: `https://www.scimigo.com/chrome-extension-beta`
   - This page includes full installation instructions and testing guidance

## File Structure:
```
public/downloads/
├── README.md (this file)
└── scimigo-extension-beta.zip (your extension ZIP)
```
